Questions fréquentes

Faut-il une connexion Internet ?

Il en faut une pour la première ouverture. Ensuite, l'application fonctionne sans connexion, avec le contenu déjà chargé.

Comment installer l'application ?

Sur Android (Chrome) : menu ⋮ puis « Installer l'application ». Sur iPhone (Safari) : bouton Partager puis « Sur l'écran d'accueil ».

Comment fonctionne le code Pro ?

Dans l'application, l'écran « Passer à Pro » affiche l'ID de votre téléphone. Vous nous l'envoyez avec votre preuve de paiement sur WhatsApp, puis vous recevez un code. Ce code ne fonctionne que sur ce téléphone. Si vous désinstallez l'application ou effacez ses données, l'ID change et il faut demander un nouveau code.

Mes données sont-elles envoyées quelque part ?

Non. Votre progression reste enregistrée sur votre téléphone.

Les questions sont-elles des textes officiels ?

Non. Ce sont des questions de révision, rédigées à partir de sources publiques. Elles ne remplacent ni les textes officiels, ni les manuels, ni la formation d'un professionnel. La législation évolue : vérifiez toujours les textes en vigueur.
